# RunningMate (Tauri)

Rust + Tauri 2 rewrite of RunningMate, with a React + TypeScript frontend built on
[shadcn/ui](https://ui.shadcn.com/) and Tailwind CSS. It reads the same `~/RunningData` folder as
the Python app.

## Prerequisites

- Rust (stable) — https://rustup.rs
- Node.js 22 and pnpm 9
- Platform dependencies for Tauri — https://tauri.app/start/prerequisites/

## Development

```sh
pnpm install
pnpm tauri dev
```

## Checks

```sh
pnpm typecheck && pnpm lint && pnpm format:check && pnpm test
cd src-tauri && cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test
```

## Layout

- `src/` — React frontend (`components/ui` is generated by `shadcn add`)
- `src-tauri/` — Rust backend; Tauri commands live in `src-tauri/src/commands/`
